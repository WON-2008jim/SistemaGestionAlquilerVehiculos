# Sistema de Gestión de Alquiler de Vehículos

Proyecto académico para el curso de Programación II en la Universidad Mariano Gálvez de Guatemala. Desarrollado por el grupo **Los Depuradores**.

## Descripción
Sistema de escritorio en Java orientado a objetos diseñado para administrar las operaciones de un servicio de alquiler de vehículos. Permite gestionar clientes, empleados, vehículos, sucursales, mantenimientos, contratos y emisión de facturas.

## Requisitos Técnicos
- **Java JDK:** 17 o superior
- **IDE:** Apache NetBeans
- **Gestor de dependencias:** Apache Maven

## Clases del Modelo
El proyecto contiene las siguientes 10 clases de entidad:
1. 'CategoriaVehiculo'
2. 'Cliente'
3. 'ContratoAlquiler'
4. 'DetalleContrato'
5. 'DetalleFactura'
6. 'Empleado'
7. 'Factura'
8. 'Mantenimiento'
9. 'Sucursal'
10. 'Vehiculo'

## Cómo Ejecutar
1. Clonar el repositorio:
   git clone https://github.com/WON-2008jim/SistemaGestionAlquilerVehiculos.git

2. Abrir el proyecto en Apache NetBeans.

3. Compilar y ejecutar desde la clase 'Main.java'.
